5.º de Secundaria

Bienvenido al área de Computación de quinto grado de secundaria.

En este grado integrarás los conocimientos adquiridos durante los años anteriores para desarrollar soluciones tecnológicas. Trabajarás con desarrollo web, bases de datos, seguridad, publicación de proyectos y emprendimiento digital.

Temas de aprendizaje

1. Desarrollo de aplicaciones

Conoce los diferentes tipos de aplicaciones y aprende a planificar interfaces y soluciones digitales.

  • ¿Qué es una aplicación?
  • Tipos de aplicaciones
  • Aplicaciones web
  • Aplicaciones de escritorio
  • Aplicaciones móviles
  • Planificación de una aplicación
  • Diseño de interfaces
Ver tema

2. Bases de datos

Aprende a organizar información mediante tablas, relaciones, consultas y operaciones básicas con SQL.

  • Conceptos de bases de datos
  • Tablas y registros
  • Campos y tipos de datos
  • Claves primarias
  • Relaciones entre tablas
  • Consultas básicas
  • Introducción al lenguaje SQL
  • Inserción y modificación de datos
Ver tema

3. Desarrollo web avanzado

Integra HTML, CSS y JavaScript para desarrollar páginas web interactivas y adaptables.

  • Arquitectura básica de un sitio web
  • HTML
  • CSS
  • JavaScript
  • Formularios web
  • Validación de datos
  • Diseño adaptable
  • Interactividad web
Ver tema

4. Integración de sistemas

Comprende cómo se relacionan frontend, backend, formularios y bases de datos dentro de un sistema.

  • Frontend y backend
  • Comunicación entre componentes
  • Formularios y procesamiento de información
  • Conexión con bases de datos
  • Gestión de información
  • Pruebas del sistema
  • Corrección de errores
Ver tema

5. Seguridad y publicación de proyectos

Aprende buenas prácticas para proteger información y publicar proyectos tecnológicos de manera segura.

  • Seguridad informática básica
  • Protección de información
  • Contraseñas y autenticación
  • Privacidad digital
  • Buenas prácticas de seguridad
  • Introducción al alojamiento web
  • Publicación de sitios web
Ver tema

6. Emprendimiento digital

Aprende a identificar necesidades y oportunidades para plantear propuestas de emprendimiento tecnológico.

  • ¿Qué es un emprendimiento digital?
  • Identificación de necesidades
  • Identificación de oportunidades
  • Propuesta de valor
  • Cliente objetivo
  • Herramientas digitales para emprender
  • Presentación de una propuesta tecnológica
Ver tema

7. Proyecto tecnológico integrador

Integra los conocimientos del grado para desarrollar una solución tecnológica que atienda una necesidad real.

Mi solución tecnológica

  • Investigación de la necesidad

  • Diseño del sistema
  • Desarrollo del proyecto
  • Integración de tecnologías
  • Pruebas y correcciones
  • Documentación
  • Presentación del proyecto
