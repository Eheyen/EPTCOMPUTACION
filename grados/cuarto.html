4.º de Secundaria

Bienvenido al área de Computación de cuarto grado de secundaria.

En este grado aprenderás los fundamentos del desarrollo web y la programación textual. Crearás páginas utilizando HTML y CSS, incorporarás interactividad mediante JavaScript y conocerás los fundamentos de las bases de datos.

Temas de aprendizaje

1. Programación textual

Conoce los fundamentos de la programación y los elementos básicos utilizados para crear programas.

  • ¿Qué es la programación textual?
  • Lenguajes de programación
  • Variables y tipos de datos
  • Operadores
  • Condicionales
  • Bucles o estructuras repetitivas
  • Funciones básicas
Ver tema

2. HTML: estructura de páginas web

Aprende a construir la estructura de una página web utilizando HTML, etiquetas y elementos semánticos.

  • ¿Qué es HTML?
  • Estructura de un documento HTML
  • Etiquetas y atributos
  • Títulos y párrafos
  • Enlaces
  • Imágenes
  • Listas
  • Tablas
  • Formularios
  • HTML semántico
Ver tema

3. CSS: diseño y estilos

Aprende a diseñar páginas web mediante colores, tipografía, dimensiones, espacios y distribución.

  • ¿Qué es CSS?
  • Formas de aplicar CSS
  • Selectores
  • Colores y fondos
  • Tipografía
  • Bordes y dimensiones
  • Modelo de caja
  • Margen y relleno
  • Flexbox
  • Diseño adaptable
Ver tema

4. JavaScript: interactividad

Conoce JavaScript y aprende a incorporar comportamiento e interactividad a las páginas web.

  • ¿Qué es JavaScript?
  • Variables
  • Tipos de datos
  • Operadores
  • Condicionales
  • Funciones
  • Eventos
  • Manipulación básica del DOM
  • Validación de formularios
Ver tema

5. Introducción a bases de datos

Aprende los conceptos fundamentales de las bases de datos y la organización de información.

  • ¿Qué es una base de datos?
  • Datos y registros
  • Tablas
  • Campos
  • Tipos de datos
  • Claves primarias
  • Relaciones entre tablas
  • Introducción a SQL
Ver tema

6. Integración de tecnologías web

Aprende a integrar HTML, CSS y JavaScript para desarrollar proyectos web organizados y funcionales.

  • HTML, CSS y JavaScript
  • Estructura de un proyecto web
  • Organización de carpetas
  • Archivos HTML
  • Archivos CSS
  • Archivos JavaScript
  • Integración de formularios
  • Pruebas y corrección de errores
Ver tema

7. Proyecto integrador

Integra HTML, CSS y JavaScript para desarrollar tu primera página web funcional.

Mi primera página web

  • Identificación de una necesidad
  • Planificación del proyecto
  • Diseño de la estructura
  • Creación del HTML
  • Aplicación de CSS
  • Incorporación de JavaScript
  • Pruebas del sitio web
  • Presentación del proyecto
Ver tema

Sesiones de aprendizaje

Las sesiones estarán organizadas de acuerdo con los temas de aprendizaje.

  • Sesión 1: Programación textual
  • Sesión 2: Introducción a HTML
  • Sesión 3: Estructura y elementos HTML
  • Sesión 4: Introducción a CSS
  • Sesión 5: Diseño de páginas web con CSS
  • Sesión 6: Introducción a JavaScript
  • Sesión 7: Bases de datos
  • Sesión 8: Integración de tecnologías web
  • Sesión 9: Proyecto integrador

Recursos educativos

  • Guías de HTML
  • Guías de CSS
  • Ejercicios de programación
  • Ejemplos de código
  • Videos educativos
  • Fichas de trabajo
  • Ejercicios de JavaScript
  • Ejercicios básicos de SQL

Proyecto integrador

Mi primera página web

En este proyecto desarrollarás una página web aplicando los conocimientos de HTML, CSS y JavaScript.

Producto final

Sitio web funcional que presente información sobre una temática seleccionada por el estudiante.
